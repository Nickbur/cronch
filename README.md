# Cronch

Cronch runs your computer's routine jobs on time, all by itself, so you never have to remember them.

Cronch is a small helper that sits quietly in the corner of the screen on Windows and Mac computers.
You tell it what should happen and when: every fifteen minutes, every weekday at nine, or just once
next Tuesday. It takes care of the rest in the background. Nightly backups, regular clean-ups, a
morning report: the chores that are easy to forget simply get done.

Every time a job runs, Cronch notes when it happened, whether it worked and what it reported, so
you can always look back and see exactly what went on. If the computer was switched off when a job
was due, Cronch catches up as soon as it is back on. There is no account to create and nothing is
sent anywhere: everything stays on your own computer.

Cronch is free for everyone, anyone can look at how it is made, and it is made by burakov. This
repository holds the complete app, everything that makes up Cronch for Windows and Mac.
